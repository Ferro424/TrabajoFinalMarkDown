# TrabajoFinalMarkDown
# 📘 Trabajo práctico: Documentación en Markdown y GitHub

## 🎯 Objetivo  
El objetivo de este trabajo es **aprender a documentar en Markdown** y **gestionar un repositorio en GitHub**, aplicando conceptos básicos de control de versiones.

---

## 📝 Instrucciones  

### 1. Crear el repositorio en GitHub  
1. Ingresa a tu cuenta de GitHub.  
2. Crea un nuevo repositorio con el nombre:  
 trabajo-markdown-Nombre-Apellidos
3. Selecciona la opción **“Add a README file”**.  

### 2. Redactar el contenido en Markdown  
Dentro del archivo `README.md`, escribe tu trabajo con la siguiente estructura:  

- **Los Tigres** con el tema elegido.  
- Una **introducción** breve (mínimo 3 párrafos).  
- Al menos **dos secciones** con subtítulos (ejemplo: `## Historia`, `## Importancia`).  
- Una **lista numerada** con ideas principales.  
- Una **lista con viñetas** con ejemplos o curiosidades.  
- Al menos **un enlace externo** a una fuente confiable.  
- Una **imagen** relacionada (puede ser desde la web).  
- Una **conclusión** de mínimo un párrafo.  

Ejemplo de estructura:  

```markdown
# Inteligencia Artificial y su futuro  

## Introducción  
La inteligencia artificial (IA) es un área de la informática que busca crear sistemas capaces de realizar tareas que requieren inteligencia humana...

## Historia de la IA  
1. Primeros experimentos en los años 50  
2. Avances en machine learning en los 80  
3. Auge del deep learning en el siglo XXI  

## Aplicaciones actuales  
- Vehículos autónomos  
- Medicina personalizada  
- Chatbots y asistentes virtuales

Más información en [Wikipedia](https://es.wikipedia.org/wiki/Inteligencia_artificial).  

## Conclusión  
La IA es una de las tecnologías más prometedoras y desafiantes de nuestro tiempo...
